1. 3D structured grid

nx, ny, nz are the number of grid points along each axis, not the number of cells.

points = nx * ny * nz

lines  = ny*nz*(nx-1) + nx*nz*(ny-1) + nx*ny*(nz-1)

faces  = nx*(ny-1)*(nz-1) + ny*(nx-1)*(nz-1) + nz*(nx-1)*(ny-1)

voxels = (nx-1) * (ny-1) * (nz-1)

Check with one cube, so nx = ny = nz = 2: 8 points, 12 lines, 6 faces, 1 voxel.
